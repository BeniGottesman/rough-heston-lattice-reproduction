# Rough Heston on the Akyildirim--Dolinsky--Soner grid

Parameter sets of Beliaeva and Nawalkha as used in arXiv:1205.3555 (Ann. Appl. Probab. 24(5) 2176--2205, 2014), with the roughness added on top.

Fixed: `K = 100`, `r = 0.05`, vol of vol `eta = 0.1`, mean reversion `kappa = 3.0`, long-run variance `theta = 0.04`, `rho = -0.7` (European tables).

Monte-Carlo: Euler--Volterra, `200` steps, `400,000` antithetic paths (European); `60,000` regression + `140,000` valuation paths and `100` exercise dates (American). Fourier: fractional Riccati, `400` steps, Gauss--Legendre `nq = 200` on `(0, 60)`.
